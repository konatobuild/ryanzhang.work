Room D4 · SPEC-v2, two chat styles

D3 brought in line with SPEC-v2 (10-28): a need is an ordinary message, taking it is a reply (“I’ll take this”), the owner may @ a member. No Need switch, no harness or model picker, no claim states, no queue. And one new switch, Style: the same room shown as channels with threads (Slack) or as one flat group chat with bubbles. Both read the same posts and replies; only the presentation differs. Fixture data, Gradient II by default. The buttons above the window only drive the prototype.
